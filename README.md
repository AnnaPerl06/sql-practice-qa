# Практика SQL для тестирования 

В этом репозитории собраны SQL-запросы для проверки целостности данных, выборки и анализа информации в реляционных базах данных.

## 🛠 Отработанные навыки и операторы
* **Базовая выборка и фильтрация:** `SELECT`, `FROM`, `WHERE`, `AND / OR`, `IN`, `BETWEEN`, `LIKE`, `IS NULL`.
* **Сортировка и ограничение вывода:** `ORDER BY`, `LIMIT`, `DISTINCT`.
* **Агрегация и группировка:** `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING`.
* **Объединение таблиц:** `INNER JOIN`.

## 📂 Содержимое репозитория
* [`queries.sql`](./queries.sql) — файл с условиями задач и готовыми SQL-запросами.
